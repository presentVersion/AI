Movement 3 · Hackathon

Conduct Your Own AI Agent

The culmination of the orchestra experience: pick a real problem, build a working agentic workflow, and conduct your autonomous AI agent live on stage.

Two-Round Event Structure

Round 1 (Movement 1 — Portfolio Benchmark): Teams build developer portfolios from reference challenges and deploy them live to the portal. Portfolios will be showcased and shared; winners of Round 1 are glorified, their stunning portfolios serving as spectacle benchmark examples for everyone.

Round 2 (Movements 2 & 3 — Agentic Hackathon): Official problem statements are revealed on the portal exclusively for Round 1 qualifiers. Note: If the number of qualifiers advancing to Round 2 is minimal, a single unified problem statement will be given to all qualifying teams (with flexibility for adjustments).

Round 2 Hackathon Mission

Transform the concepts learned in Movements I & II into an autonomous, interactive system. Rather than building another simple prompt wrapper or chatbot, your team will engineer an agent capable of multi-step reasoning, external tool execution, and continuous state persistence to solve the revealed problem statement.

Team Guidelines & Tracks

  • Team Size: 2–4 students per team.
  • Track A — Developer Co-Pilots: Automated code review, git issue triaging, or test generation agents.
  • Track B — Research & Synthesis: Web-crawling, multi-source verification, and report synthesis agents.
  • Track C — Creative & Media Orchestration: Agents that coordinate multi-modal generation (audio, graphics, copy).

Deliverables & Evaluation

  1. Live Demonstration (5 mins): Trigger the agent live, explain its decision tree, and showcase autonomous tool use.
  2. Architecture Diagram: Visual representation of agent state, triggers, memory, and tool integration (e.g., n8n, LangChain, or custom API loop).
  3. Source Code / Workflow: Public repository or exported workflow configuration with documentation.
